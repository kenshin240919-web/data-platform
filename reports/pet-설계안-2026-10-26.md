# 내근처 동물병원(반려동물) 설계안 (2026-10-26)

> 사용자 요청: "다음 사이트 기획안 만들어줘".
> 결론 먼저: 다음 사이트는 **반려동물 사이트**를 권합니다. 가칭은 '내근처 동물병원', 부제 "우리 아이 아플 때 어디로?", 주소 `pet.guidejung.com`(안)입니다.
> 핵심은 **① 내 주변 동물병원·24시 동물병원**과 **② 지금 문 연 동물약국**입니다. ②는 약국 사이트의 영업 시간 데이터와 연결하는데, 다른 곳에 거의 없는 기능입니다.
> 그다음 **③ 보호 중인 유기동물**(사진·공고 마감일)과 **④ 펫호텔·애견카페·펫택시**로 넓혀, 한 번 오고 끝나지 않게 합니다.
> 이 세션에서 공공 파일을 직접 받아 숫자를 확인했습니다(2장). 확인하지 못한 것은 '미확인'으로 따로 적었습니다.

반려동물을 고른 이유는 세 가지입니다.

1. 급한 검색 수요가 있습니다. "24시 동물병원", "근처 동물병원", "동물약국"이 그 예입니다.
2. 다시 올 이유가 많습니다. 병원 즐겨찾기, 보호동물, 산책 날씨가 있습니다.
3. 이미 있는 사이트 3곳과 데이터가 바로 이어집니다. 약국 영업 시간, 여행 반려동물 조건, 날씨입니다.

검색량·광고 단가 숫자는 확인하지 못했습니다.

## 2. 데이터 (모두 무료 공공데이터)

### 2-1. 이 세션에서 직접 받아 확인한 것 (10/26)
LOCALDATA 파일은 활용신청이 필요 없습니다. 휴식·서비스센터 수집기와 같은 방법(브라우저 UA + Referer)으로 받습니다.
- 주소: `https://file.localdata.go.kr/file/download/{이름}/info`
- 좌표: EPSG:5174. 휴식 수집기의 `tm5174` 변환을 그대로 씁니다.

| 파일 이름 | 내용 | 전체 행 | **영업 중** | 좌표 있음 | 전화 있음 |
|---|---|---|---|---|---|
| `animal_hospitals` | 동물병원 | 10,659 | **5,492** | 5,278 | 3,062 |

**알게 된 것**
- **동물병원 진료 시간은 데이터에 없습니다.** 이름에 '24'가 들어간 곳은 193곳(예: '24시 ○○동물메디컬센터')입니다.
  - 이것을 '24시 동물병원'으로 묶되, "이름 기준 — 방문 전 전화 확인"이라고 분명히 적습니다.
  - 진료 시간은 상세의 '🟢 네이버 지도에서 진료 시간 보기' 링크로 보냅니다. 휴식 사이트와 같은 방식입니다.
  - 네이버 내용은 가져오지 않습니다(약관).
- **동물약국은 대부분 사람 약국입니다.** 13,715곳의 이름에 '약국'이 들어갑니다.
  - 약국 사이트 데이터 `apps/pharmacy/data/pharmacies.json`(국립중앙의료원, 요일별·공휴일 영업 시간)과 이름 + 도로명주소로 맞춰 봤습니다. **11,048곳(80%)이 맞았습니다.**
  - 그래서 **'지금 문 연 동물약국'을 실제 영업 시간으로 계산할 수 있습니다.** 약국 사이트의 `statusOf`를 다시 씁니다.
  - 맞지 않은 약 2,700곳은 "영업 시간 정보 없음"으로 둡니다.
- 지역 분포(동물병원): 경기 1,413·서울 986·광주전남 369·경북 367·경남 366 … 세종 33. 시도 16곳 모두에 있습니다.
- 2025년 이후 새로 문 연 동물병원은 479곳입니다. '새로 생긴 동물병원' 묶음을 만들 수 있습니다.
- 위탁관리업 이름에는 동물병원도 섞여 있습니다(병원이 호텔을 함께 신고). 같은 이름 + 주소는 합칩니다.

### 2-3. 확인하지 못한 것
- **동물미용업(애견 미용)** LOCALDATA 파일 이름을 못 찾았습니다(10개 이름을 시험했으나 404). 2단계에서 data.go.kr 목록으로 다시 찾습니다.
- **동물장묘업**도 같은 이유로 미확인입니다.
- 좌표가 없는 곳(동물병원 214·동물약국 676)은 기존 방식으로 처리합니다. 무료 쿼터 안에서 카카오로 30일마다 다시 확인합니다.

## 3. 사이트 구성 (휴식·약국 사이트 구조를 그대로 씀)

- **수집**: `scripts/collect-pet.py` + Actions `pet-collect.yml`(매일, 다른 수집과 겹치지 않는 시각)
  1. LOCALDATA 5종에서 영업 중만 고릅니다.
  2. 좌표를 변환하고, 같은 이름 + 주소는 합칩니다.
  3. 동물약국은 약국 데이터와 맞춰 `pharmacy_id`를 붙입니다.
  4. 지역 코드는 weather `regions.json`과 같게 합니다.
  5. 결과는 `apps/pet/data/places.json`(약 3만 곳, 수 MB 예상)에 씁니다. D1은 쓰지 않습니다.
- **정적 페이지(Next)**:
  - 메인 `NearPet` — 3초 답, 24시 띠, 종류별 수
  - 종류 페이지 `/hospital`·`/24h`·`/pharmacy`·`/hotel`·`/cafe`·`/taxi`
  - `/region`·`/region/{코드}`·`/region/{코드}/{종류}`(3곳 이상)
  - `/adopt`(보호 중인 아이들, 2단계)
  - `/guide`(아플 때 순서·동물약국과 동물병원 차이·동물등록)
  - `/search`(noindex)·안내 3종·sitemap·rss
- **Worker `guidejung-pet`**:
  - 상세 `/place/{id}` — VeterinaryCare·Pharmacy·LocalBusiness JSON-LD·FAQ·근처 같은 종류·근처 24시·지금 문 연 동물약국

  - 동물약국 '지금 상태'는 약국 데이터의 시간표로 계산합니다(5분 단위 캐시).

## 4. 표시 원칙
- 진료 시간·진료 과목·가격·후기는 데이터에 없으므로 **지어내지 않습니다.** '24시'는 이름 기준이라는 것을 화면에 밝힙니다.
- 응급 안내 문구는 사실만 씁니다. 예: "숨쉬기 힘들어하거나 경련하면 바로 가까운 24시 동물병원에 전화". 이런 행동 요령은 공식 자료로 확인한 뒤 넣습니다.
- 보호동물 사진은 API 이용 조건을 확인한 뒤에만 보여 줍니다. 확인 전에는 수·품종·공고 마감일만 쓰고 보호소로 연결합니다.

# traffic.guidejung.com 설계안 (2026-10-15)

> 공통 원칙: `reports/서비스-공통원칙-클릭체류.md` — **클릭 유발·체류가 1순위**. 이 설계서도 "클릭·체류 설계"를 맨 앞에 둔다.
> trip·weather·charge와 같은 저장소(`apps/traffic`) + 별도 Cloudflare Worker(`guidejung-traffic`).

## 1. 클릭·체류 설계 (최우선)
교통 사이트에 들어오는 사람의 질문은 대부분 다음 다섯 가지다. 각각 3초 안에 답하고, 다음 행동으로 계속 이어지게 한다.

| 검색 의도 | 3초 답 (첫 화면 맨 위 한 줄) | 다음 행동 |
|---|---|---|
| "경부고속도로 교통상황" | "지금 경부선 서울→부산 **막히는 구간 3곳**(안성~천안 18km/h)" | 막힌 구간 CCTV 바로 보기 → 우회 노선 → 휴게소 |
| "고속도로 CCTV" | 노선을 고르면 **CCTV 썸네일 목록**이 바로 뜸 | 누르면 영상 재생, 옆 CCTV로 넘기기(◀ ▶) |
| "○○휴게소" | "**대표 음식 ○○ · 휘발유 1,6xx원 · 전기차 충전 가능 3대**" | 다음 휴게소(진행 방향 순), 충전소(charge), 주변 여행지(trip) |
| "주유소 최저가" (2단계) | "**내 주변 3km 최저가 휘발유 1,6xx원**(평균보다 −80원)" | 가격 순 목록 → 길찾기 → 지역 평균 비교 |
| "명절 귀성길 소요시간" (시즌) | "**지금 출발하면 서울→부산 6시간 10분**(평소 +1시간 50분)" | 시간대별 예상 → 출발 추천 시각 → 휴게소 |

1. **노선 페이지가 중심**: `/road/{노선}`(경부선·영동선·서해안선 등)에서 위→아래로 **IC 순서대로** 구간 속도 색깔(🟢 원활 / 🟡 서행 / 🔴 정체), 사고·공사 아이콘, CCTV, 휴게소를 한 줄에 배치한다. 스크롤만 해도 노선 전체를 따라 내려가므로 체류가 길어진다.
2. **CCTV 넘겨보기**: CCTV를 누르면 영상이 열리고, ◀ ▶로 앞뒤 CCTV로 바로 넘어간다(진행 방향 순). "다음 CCTV" 클릭이 반복되는 구조.
3. **지금 가장 막히는 도로 TOP 10**: 메인과 `/now`에 전국 고속도로 정체 구간 순위(길이·속도). 숫자가 계속 바뀌어 다시 보게 된다.
4. **사고·통제 띠**: weather의 특보 띠처럼 모든 페이지 상단에 "지금 고속도로 사고 N건 · 공사 통제 N건" 띠 → `/incidents`.
5. **휴게소 상세**: 대표 음식·편의시설·주유 가격·**전기차 충전기 상태(charge 연결)**·주변 가볼만한곳(trip)·도착 지역 날씨(weather). 하단에 "같은 노선 다음 휴게소 3곳".
6. **롱테일 정적 페이지**: "{노선} 교통상황"(약 30), "{노선} CCTV", "{휴게소} 휴게소"(약 200), "{시군구} 주유소 최저가"(2단계, 약 230), "{시군구} 과속카메라"(2단계).
7. **재방문**: 자주 보는 노선·CCTV·휴게소 즐겨찾기, 최근 본 노선(브라우저 저장). 다시 오면 즐겨찾기 노선의 지금 상태부터 보여 준다.
8. **사이트 간 순환**: 노선·휴게소 → 목적지 날씨(weather 특보·눈비) / 휴게소 → 충전소(charge) / 목적지 → 가볼만한곳(trip). weather·charge·trip에서도 "가는 길 교통상황" 카드로 traffic에 연결.
9. **시즌 특집**: 설·추석·여름휴가 직전에 "귀성·귀경 예상 소요시간" 페이지를 메인 최상단에 올린다(검색량이 크게 몰리는 시기).

광고: 3초 답 아래 1곳, 노선 목록 중간 1곳, 페이지 하단 1곳. **CCTV 영상·재생 버튼·◀ ▶ 버튼과는 간격을 둔다**(오클릭 유도로 보일 수 있어 애드센스 정책상 위험).

## 3. 데이터 (모두 무료, 활용신청 필요)
| 우선 | 제공처 | 데이터 | 용도 | 키 |
|---|---|---|---|---|
| 필수 | **국가교통정보센터(ITS)** `openapi.its.go.kr` | CCTV 화상자료(`cctvInfo`: 고속도로 ex/국도 its, 좌표 범위, 영상 URL·위치·이름), 교통소통정보(`trafficInfo`: 링크별 속도), 돌발상황정보(사고·공사) | CCTV·구간 속도·사고 | **its.go.kr 회원가입 → 마이페이지 → 인증키 신청**(공공데이터포털 키와 별개) |
| 필수 | **한국도로공사 고속도로 공공데이터 포털** `data.ex.co.kr` | 휴게소 대표음식·편의시설·주유소 가격, 노선·IC 목록, 실시간 소통·영업소간 통행시간, 명절 교통예보 | 휴게소·노선 구조·소요시간 | **data.ex.co.kr 회원가입 → 인증키 신청**(별개) |
| 2단계 | **오피넷(한국석유공사)** `opinet.co.kr` | 지역별 최저가·내 주변 주유소·평균 유가 | 주유소 최저가 | 오피넷 오픈API 신청(개인 이용 조건·한도 미확인) |
| 2단계 | 공공데이터포털 | 전국무인교통단속카메라표준데이터(15013094) | 과속카메라 | 기존 공통 키로 활용신청 |
| 참고 | 공공데이터포털 | 국토교통부_교통소통정보(15040463), 경찰청_교통 CCTV 영상 정보(15148511) | ITS 대체·도시 CCTV | 기존 공통 키 |

- 정확한 요청 변수·호출 한도·응답 형식은 **키 발급 후 표본 호출로 확정**한다(charge 때처럼 3-1장에 실측 기록).
- 이 클라우드 세션에서는 위 도메인(`openapi.its.go.kr`, `data.ex.co.kr`, `www.opinet.co.kr`, `api.data.go.kr`)이 아직 막혀 있어 미리 호출해 보지 못했다(10/15 확인). 클라우드 환경 허용 도메인에 추가가 필요하다.

### 접속 시험 (10/15)
- ITS 인증키 발급(운영, 월 1,000건, 사용처 https://traffic.guidejung.com, 교통소통·돌발·CCTV·교통예측·VDS·VMS·주의운전구간·VSL·위험물질 사고·재난상황 신청). 키는 저장소에 두지 않음(Worker Secret `ITS_API_KEY` 예정).
- **월 호출 한도 1,000건**(서비스별인지 합계인지 미확인) → 실시간 5분 갱신은 불가. 정적 정보(CCTV 위치)는 하루 1회, 사고·소통은 전국 1회 호출 후 1시간 안팎 캐시, 부족한 실시간은 도로공사·공공데이터포털로 보완.
- 클라우드 허용 도메인 추가 후 `data.ex.co.kr` 접속 확인. `openapi.its.go.kr`(443·9443)는 프록시는 통과하나 **ITS 서버가 TLS 연결을 바로 끊음** → 해외 IP 차단 추정(미확인). Cloudflare Worker(국내 방문자는 보통 서울 데이터센터)·GitHub Actions(미국)에서도 막힐 수 있음 → 컴퓨터(국내)·Worker 시험 주소로 확인 필요.
- 대안(해외 접속 가능 확인된 `apis.data.go.kr`): 국토교통부_교통소통정보(15040463), 경찰청_교통 CCTV 영상 정보(15148511) 활용신청 권장.

### 확인이 꼭 필요한 위험 요소
1. **CCTV 영상 이용 조건**: 광고가 있는 사이트에서 영상 표시가 허용되는지, 출처 표기 방식(ITS 오픈데이터 이용약관). 허용되지 않으면 "CCTV 위치 + 공식 사이트 링크"로 대체.
2. **CCTV 영상 주소 만료**: 영상 URL이 일정 시간 후 만료된다고 알려져 있음 → Worker가 누를 때마다 새 주소를 받아 짧게(수 분) 캐시.
3. **http 영상 주소**: 영상 주소가 http면 https 사이트에서 재생이 막힌다(혼합 콘텐츠). 이 경우 공식 플레이어 링크로 연결.
4. **영상 형식**: HLS(m3u8)면 사파리는 바로, 크롬은 hls.js(무료 라이브러리)로 재생.

## 4. 구조
```
apps/traffic/                 Next.js 정적 페이지(노선·휴게소·CCTV 목록, SEO)
apps/traffic/worker/          Cloudflare Worker
  /api/road?route=            구간 속도·사고(2~5분 캐시)
  /api/cctv?route= | ?id=     CCTV 목록·새 영상 주소(수 분 캐시)
  /api/incidents              전국 사고·통제(2~5분 캐시) — 상단 띠
  /api/gas?code=              (2단계) 주유소 가격(1시간 캐시)
apps/traffic/data/            정적 스냅샷: 노선·IC 순서·휴게소·CCTV 위치(GitHub Actions 매일 갱신)
apps/traffic/wrangler.jsonc   Worker guidejung-traffic, 도메인 traffic.guidejung.com
.github/workflows/traffic-snapshot.yml  매일 정적 정보 수집 → 커밋 → 자동 재배포
```
- charge에서 검증한 방식을 그대로 쓴다: 정적 정보는 매일 스냅샷(검색 노출·첫 화면 속도), 실시간은 Worker 캐시 + 오래된 사본 즉시 표시 후 뒤에서 갱신.
- 지역은 weather `regions.json`(시군구 중심 좌표) 재사용. 노선·휴게소에서 가장 가까운 시군구로 weather·trip·charge 링크를 만든다.
- 키는 Cloudflare Worker Secret(`ITS_API_KEY`, `EX_API_KEY`, 2단계 `OPINET_KEY`)과 GitHub Secret에만 둔다.

## 5. 비용
- API 모두 무료(호출 한도만 있음), GitHub Actions(공개 저장소)·Cloudflare 무료 플랜으로 시작.
- CCTV 영상은 방문자 브라우저가 원본 서버에서 직접 받으므로 Cloudflare 트래픽 비용이 없다.
- 실시간 호출이 많아 Workers 무료 한도(하루 10만 요청·요청당 CPU 10ms)를 넘으면 유료(월 $5) 필요 → 그때 미리 알리고 승인.

## 6. 단계
1. **사용자**: ITS 인증키(its.go.kr), 한국도로공사 인증키(data.ex.co.kr) 신청. 2단계용 오피넷 키는 나중에.
2. **사용자**: 클라우드 환경 허용 도메인에 `openapi.its.go.kr`, `data.ex.co.kr` 추가(2단계 때 `www.opinet.co.kr`, `api.data.go.kr`).
3. 표본 호출로 노선·IC·휴게소·CCTV 건수, 한도, 영상 주소 형식(https·HLS·만료) 확인 → 이 문서 3·5장 확정, CCTV 이용조건 확인.
4. 정적 스냅샷 스크립트 + GitHub Actions.
5. 사이트 MVP(메인·노선·CCTV·휴게소·사고·TOP 10), 애드센스·Clarity·SEO 파일.
6. 실시간 Worker(구간 속도·사고·CCTV 주소).
7. weather·charge·trip과 서로 연결("가는 길 교통상황", "휴게소 충전소").
8. **사용자**: Cloudflare Worker 생성·Secret·도메인 연결, Clarity 프로젝트 ID, 검색엔진 등록.
9. 2단계: 주유소 최저가(오피넷), 과속카메라, 명절 특집.

## 7. 확인 필요(미확정)
- ITS·도로공사 일일 호출 한도, 돌발상황 API 이름·변수(검색으로는 확인 못 함)
- 구간 속도의 단위(링크 ID ↔ 노선·IC 매핑 방법)
- 휴게소 데이터의 노선·방향(상행/하행)·IC 순서 제공 여부
- 오피넷 오픈API의 개인 사용 가능 여부·한도
- CCTV 영상 이용 조건(광고 사이트 표시 허용 여부)

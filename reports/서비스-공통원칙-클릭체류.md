# GuideJung 모든 사이트 공통 설계 원칙: 클릭과 체류 (2026-10-09)

> **사용자 기본 원칙: "가장 중요한 것은 사람들의 클릭을 유발해야 하고, 사이트에 접속하면 계속 체류하게 만들어야 한다."**
> trip·weather·charge·traffic·academy·home 등 모든 하위 사이트의 설계·화면·기능 결정은 이 원칙을 1순위 기준으로 한다.
> 새 사이트 설계서는 반드시 "클릭·체류 설계" 장을 맨 앞에 둔다.

## 1. 공통 원칙 10가지
1. **3초 안에 답**: 검색으로 들어온 사람이 찾던 답(값·결론)을 첫 화면 맨 위에 한 줄 요약으로 보여 준다. 답이 없으면 바로 나간다.
2. **다음 행동 카드**: 답 바로 아래에 "그다음 궁금할 것" 카드 3~4개를 둔다. 각각 사이트 안 다른 페이지로 연결한다.
3. **넘기고 펼치는 정보**: 가로 스크롤 목록, 펼치기, 탭으로 손이 계속 움직이게 한다.
4. **비교·순위·목록**: "TOP 10", "가장 ~한 곳", "어제와 비교"처럼 끝까지 보게 되는 콘텐츠를 만든다.
5. **막다른 페이지 금지**: 모든 페이지 끝에 관련 페이지(주변·비슷한·같은 지역)를 3개 이상 둔다.
6. **사이트 간 순환**: GuideJung 사이트끼리 서로 링크한다. 예: 날씨 → 여행, 여행 → 충전소, 교통 → 날씨. 한 사이트에 들어온 사람이 네트워크 안에서 계속 돌게 한다.
7. **재방문 장치**: 즐겨찾기, 최근 본 항목, 내 위치·내 지역을 브라우저에 기억한다. 다시 오면 바로 이어서 보게 한다.
8. **롱테일 검색 페이지 대량 생성**: "지역 + 주제" 조합마다 정적 페이지를 만든다. 검색 유입 입구를 최대한 넓힌다.
9. **빠른 로딩**: 정적 페이지, 캐시, 이미지 지연 로딩을 쓴다. 느리면 클릭하기 전에 나간다.
10. **신뢰 표시**: 출처와 기준 시각을 항상 보여 준다. 정확하다고 믿어야 다시 온다.

## 2. 광고와의 관계 (애드센스 정책 준수)
- 클릭은 **콘텐츠로** 유도한다. 페이지뷰와 체류가 늘면 광고 노출이 자연히 늘어난다.
- 금지 사항(계정 정지 위험):
  - "광고를 클릭해 주세요", "응원해 주세요" 같은 문구
  - 광고를 메뉴·버튼·본문처럼 보이게 배치
  - 광고를 가리키는 화살표나 애니메이션
  - 클릭 보상, 지인에게 클릭 부탁
- 광고 위치: 첫 답 아래, 본문 중간, 관련 목록 위. 메뉴·버튼·페이지 번호와는 간격을 둔다. "광고" 표시를 붙인다.
- 근거: [AdSense Program policies](https://support.google.com/adsense/answer/48182)

## 3. 사이트별 클릭·체류 설계 초안
### trip (운영 중) — 보강 후보
- 상세 페이지 상단에 "이곳 날씨" 카드 추가 (weather 오픈 후, weather로 연결)
- "이번 주말 맑은 곳의 가볼만한곳" 목록 (weather 데이터 활용)
- 즐겨찾기·최근 본 여행지
- 상세 하단 "비슷한 곳"(같은 유형·조건) 목록 추가

### weather — `reports/weather-설계안-2026-10-09.md` 참고
- 지금 날씨와 한 줄 요약, 생활 카드(옷차림·우산·미세먼지·빨래), 시간별·10일 예보, 순위, 주말 날씨, 여행지 날씨 페이지, trip 연계

### charge (전기차 충전소)
- **3초 답**: 내 주변에서 **지금 사용 가능한** 충전기 수와 가장 가까운 충전소
- **다음 행동 카드**: 급속만 보기, 무료 주차 충전소, 24시간 충전소, 요금 비교
- **비교·순위**: 지역별 충전소 많은 곳, 고속도로 휴게소 충전소 현황, 충전 요금 싼 순
- **롱테일 페이지**: "{시군구} 전기차 충전소", "{휴게소} 충전소", "{여행지} 근처 충전소"(trip 연계)
- **순환**: 충전하는 동안 근처 가볼만한곳·카페(trip), 목적지 날씨(weather)
- **재방문**: 자주 가는 충전소 즐겨찾기, 마지막으로 본 충전소 상태
- 데이터 후보: 환경부(한국환경공단) 전기자동차 충전소 정보 (활용신청 필요, 미확인)

### traffic (교통·CCTV)
- **3초 답**: 지금 막히는 구간 요약, 내 경로의 소요 시간 변화
- **다음 행동 카드**: CCTV 보기, 사고·통제 정보, 주말·명절 혼잡 예측
- **비교·순위**: 지금 가장 막히는 도로 TOP 10, 귀성·귀경 시간대별 추이
- **롱테일 페이지**: "{도로명} 교통상황", "{IC/지역} CCTV", "{여행지} 가는 길"
- **순환**: 목적지 날씨(weather), 휴게소 충전소(charge), 목적지 여행지(trip)
- 주의: CCTV 영상 URL 만료·이용조건 확인 필요

### academy (학원·교습소)
- **3초 답**: 우리 동네 학원 수와 과목별 평균 수강료
- **다음 행동 카드**: 과목별 비교, 수강료 낮은 순, 신규 개원
- **비교·순위**: 지역별 평균 수강료 순위, 과목별 학원 많은 동네
- **롱테일 페이지**: "{동/구} {과목} 학원", "{학원명} 수강료"
- **재방문**: 관심 학원 저장, 비교 목록
- 주의: 공개 수강료의 기준 기간·과정·갱신일을 함께 표시

### home (맨 마지막)
- 모든 사이트의 입구 역할. 각 사이트의 "3초 답" 카드를 모아 보여 주고, 해당 사이트로 보낸다.

## 4. 성과 확인 방법
- 애드센스 보고서의 페이지 RPM, 광고 단위별 클릭률
- Search Console의 노출·클릭·검색어 (어떤 롱테일이 들어오는지)
- 체류 시간·페이지뷰를 정밀하게 보려면 분석 도구가 필요하다. 넣을지는 사용자와 결정한다 (넣으면 개인정보 안내 갱신 필요).

※ 이 문서의 클릭·체류 기법은 일반적인 웹 운영 경험에 근거한 설계 판단이며, 실제 효과는 운영 데이터로 확인해 조정한다.

# charge.guidejung.com 설계안 (2026-10-14)

> 공통 원칙: `reports/서비스-공통원칙-클릭체류.md` — **클릭 유발·체류가 1순위**. 이 설계서도 "클릭·체류 설계"를 맨 앞에 둔다.

## 1. 클릭·체류 설계 (최우선)
전기차 운전자의 질문은 거의 하나다: **"지금 가까운 곳에 비어 있는 충전기가 있나?"** 이 답을 3초 안에 주고, 다음 행동(경로·요금·주변)으로 계속 이어지게 한다.

1. **3초 답**: 첫 화면 맨 위에 "📍 내 주변 1km 안에 **지금 충전 가능한 급속 7대**" 한 줄과 가장 가까운 3곳 카드(거리·사용 가능 대수·급속/완속·요금).
2. **다음 행동 카드**: 급속만 보기 · 24시간 · 무료 주차 · 요금 싼 곳 · 고속도로 휴게소. 누르면 필터된 목록으로 이동.
3. **상태 색깔**: 충전소마다 🟢 비어 있음 / 🟡 일부 사용 중 / 🔴 모두 사용 중 / ⚫ 점검·통신 끊김. 목록을 훑어보며 계속 누르게 한다.
4. **충전소 상세 페이지**: 충전기별 상태·타입(DC콤보·차데모·AC3상·완속)·용량(kW)·운영기관·이용시간·주차료·마지막 상태 갱신 시각. 하단에 **"충전하는 동안 갈 만한 곳"(trip 여행지·축제 반경 1~3km)**과 **"지금 이곳 날씨"(weather)**.
5. **비교·순위**: "○○구 충전소 많은 동네", "운영기관별 충전 요금 비교", "고속도로 휴게소 충전기 현황(상행/하행)".
6. **롱테일 정적 페이지**: "{시군구} 전기차 충전소"(약 256), "{휴게소명} 충전소", "{충전소명}"(충전소 단위 상세), "{trip 여행지} 근처 충전소".
7. **재방문**: 즐겨찾기 충전소, 최근 본 충전소·지역(브라우저 저장). 다시 오면 즐겨찾기의 현재 상태부터 보여 준다.
8. **사이트 간 순환**: trip 상세 → "근처 충전소", weather 지역 → "이 지역 충전소", charge 상세 → trip·weather.

광고: 3초 답 아래 1곳, 목록 중간 1곳, 상세 하단 1곳. 버튼·지도 조작부와 간격을 둔다(애드센스 정책).

## 2. 페이지 구성
| 경로 | 내용 |
|---|---|
| `/` | 내 위치/최근 지역 기준 가까운 충전소, 바로가기 카드, 시도 목록 |
| `/region/{시도}` · `/region/{시군구}` | 지역 충전소 목록(정적 HTML) + 실시간 상태(브라우저에서 갱신), 통계(급속·완속 수) |
| `/station/{statId}` | 충전소 상세(충전기별 상태·타입·요금·이용시간) + 주변 여행지·날씨 |
| `/highway` | 고속도로 휴게소 충전소 목록·상태 |
| `/fast`, `/free-parking`, `/24h` | 조건별 목록 |
| `/price` | 운영기관별 충전 요금 안내(공식 출처 확인 후) |
| `/about`, `/data-policy`, `/privacy` | 안내·출처·광고/Clarity 고지 |

## 3. 데이터 (활용신청 필요, 무료)
| 우선 | API | 용도 | 상태 |
|---|---|---|---|
| 필수 | **한국환경공단_전기자동차 충전소 정보** (`apis.data.go.kr/B552584/EvCharger`) — `getChargerInfo`(충전소·충전기 정보), `getChargerStatus`(최근 N분 상태 변경) | 위치·타입·운영기관·이용시간·주차료·상태 | 엔드포인트 존재 확인(10/14, "등록되지 않은 서비스키" 응답) → **활용신청 필요** |
| 참고 | 전국전기차충전소표준데이터(파일) | 실시간 API 장애 시 기본 목록 | 미확인 |
| 선택 | 한국도로공사 휴게소 정보 | 휴게소 이름·노선·방향 | 미확인 |

- 충전기 수가 전국 수십만 대 규모로 알려져 있어 **정적 정보는 하루 1회**, **상태는 몇 분 단위 변경분**만 받는 구조로 설계한다. 정확한 건수·한도·요청 변수(시도·시군구 필터, period 등)는 활용신청 후 표본 호출로 확정한다.

## 3-1. 실측 결과 (2026-10-14, 활용신청 승인 후)
- 활용신청 승인, 일일 트래픽: `getChargerInfo` 1,000 / `getChargerStatus` 1,000 (개발계정).
- **전국 충전기 527,554대**(서울 76,219대). 예: 관악구(zscode=11620) 1,729대·348개 충전소, 응답 1.4MB·약 3.7초.
- `numOfRows=9999` 한 페이지 조회 가능, `zcode`(시도)·`zscode`(시군구) 필터 동작.
- `getChargerStatus` `period=5` → 최근 5분 상태 변경 약 9,100건(전국, 1페이지로 수용).
- 주요 필드: statNm·statId·chgerId·chgerType·addr·lat·lng·useTime·busiNm·busiCall·stat·statUpdDt·output(kW)·parkingFree·limitYn·limitDetail·zcode·zscode·kind·delYn.
- 상태(stat) 표본 분포(관악구): 2(대기) 1,370 · 3(충전 중) 198 · 9(미확인) 129 · 1(통신이상) 27 · 5(점검) 4 · 4(운영중지) 1. 코드 의미는 일반적으로 1 통신이상·2 충전대기·3 충전중·4 운영중지·5 점검중·9 상태미확인으로 알려져 있음(공식 명세서로 최종 확인 필요).
- 충전기 타입(chgerType) 02(AC완속)가 대부분, 04(DC콤보)·06 등 급속. 09 이후 신규 코드 의미는 명세서 확인 필요.

### 호출 계획
| 작업 | 방식 | 호출/일 |
|---|---|---|
| 전국 충전소 정보 전체 갱신 | 9,999건씩 약 53페이지, 하루 1회 | 약 53 (한도 1,000) |
| 실시간 상태 | `getChargerStatus` period=5 전국 1회 × 5분마다 | 약 288 (한도 1,000) |

### 저장 방식 결정 필요
- 전국 원본은 수백 MB 규모라 저장소에 매일 커밋하기에는 크다. **충전소 단위로 묶어 필요한 필드만 남기고(시군구별 JSON 분할)**, GitHub Actions가 빌드·배포까지 직접 하는 방식(데이터는 커밋하지 않음)을 1안으로 검토한다. 이 경우 GitHub Secret에 공공데이터 키와 Cloudflare API 토큰이 필요하다.

## 4. 구조 (trip·weather와 같은 저장소, 별도 Worker)
```
apps/charge/                Next.js 정적 페이지(지역·충전소 상세, SEO) + 정적 데이터(JSON)
apps/charge/worker/         Cloudflare Worker: /api/status (실시간 상태, 캐시)
apps/charge/wrangler.jsonc  Worker 이름 guidejung-charge, 도메인 charge.guidejung.com
.github/workflows/charge-data.yml  매일 1회 충전소 정보 수집 → JSON 커밋 → 자동 재배포
```
- **정적 정보 수집은 GitHub Actions 예약 실행**(공개 저장소는 무료)으로 한다. 컴퓨터가 꺼져 있어도 매일 갱신된다. 키는 GitHub 저장소 Secret에만 둔다.
- **실시간 상태는 Worker**가 받아 짧게(1~5분) 캐시한다. 응답이 늦으면 "○분 전 상태"로 표시하고 지어내지 않는다.
- 지역 매핑은 weather의 `regions.json`(시군구 중심 좌표)을 재사용한다.

## 5. 비용
- API·GitHub Actions(공개 저장소)·Cloudflare 무료 플랜으로 시작.
- 상태 갱신 호출이 늘어 무료 한도를 넘으면 Workers 유료(월 $5)가 필요할 수 있음 → 그때 미리 알리고 승인.

## 6. 단계
1. **사용자**: 공공데이터포털에서 "한국환경공단_전기자동차 충전소 정보" 활용신청, 승인·일일 한도 확인
2. 표본 호출로 건수·필드·상태 코드·필터 변수 확인 → 이 문서 3·5장 확정
3. GitHub Actions 수집 스크립트 + 정적 JSON 구조
4. 사이트 MVP(메인·지역·충전소 상세·조건 목록), 애드센스·Clarity·SEO 파일
5. 실시간 상태 Worker
6. trip·weather와 서로 연결("근처 충전소")
7. **사용자**: Cloudflare Worker 생성·도메인 연결·Clarity 프로젝트 ID·검색엔진 등록

## 7. 확인 필요(미확정)
- 개발계정 일일 호출 한도, 1회 최대 건수(numOfRows)
- 상태 코드 정의, `getChargerStatus`의 period·지역 필터 지원 여부
- 충전 요금 데이터 제공 여부(없으면 운영기관 공식 요금표 링크로 대체)
- 정적 데이터 총 용량(충전소 단위로 묶어 줄이는 방안)

## 0. 클릭·체류 설계 (가장 먼저)

**3초 답(첫 화면 맨 위)**: "📍 ○○구 근처 지금 모집 중 **N건** — 오늘·내일 마감 **M건** · 공공기관 **K건**"
- 위치는 `useMyPosition()` 칸 중심만 서버로, 거리는 `fixKmNow`로 휴대폰 안에서 다시 잼(다른 사이트와 같은 규칙). 위치가 없으면 `/api/where` → 시도 버튼.

**다음 클릭을 부르는 장치**
1. **출퇴근 거리 칩**: 🚶 걸어서 1km · 🚌 버스 5km · 🚗 차로 15km(기본 5km). 일자리 사이트들이 잘 안 주는 '집에서 얼마나 먼가'를 첫 기준으로 둔다.
2. **일하는 방식 칩**: 알바·파트타임 / 정규직 / 계약직 / 공공기관·공무원 / 어르신 일자리 / 청년 인턴 — 칩마다 건수.
3. **마감 D-day**: 오늘 마감·이번 주 마감 띠. 지원을 미루면 놓친다는 이유로 다시 오게 한다.
4. **시급 한눈에**: 시급·월급 공고는 '최저임금보다 얼마 더'를 표시한다(2026년 10,320원 — 고시 원문 확인 후 반영, 2027년 금액은 고시 뒤 교체). 같은 시군구 같은 직종 시급 중앙값과 비교해 사실만 보여 준다.
5. **새 공고 알림**: near 웹 푸시에 '💼 우리 동네 새 일자리'(시군구·직종 고르기, 하루 1번, 새로 올라온 것이 있을 때만) 주제를 더한다.
6. **지원 준비물 → 다른 내근처 사이트**:
   - 음식점·급식 알바의 건강진단결과서(보건증) → 병원·보건소(데이터 확인 필요)
   - 이력서에 붙일 증명서(졸업·경력·자격) → 서류 사이트 무인민원발급기·주민센터
   - 구직 중 받을 수 있는 지원(국민취업지원제도·청년 혜택 등) → 혜택 사이트 `고용·창업` 분야 838건
   - 면접 길 → 주차장·날씨, 차로 출근 → 주유소
7. **기관별 페이지**: '○○구청 채용', '○○공사 채용' — 공고가 끝나도 남는 페이지(지난 공고 수·보통 뽑는 시기)라 검색 유입이 쌓인다.

**광고**: 상세 2곳·목록 1곳(다른 사이트와 같음). '지원하기' 버튼 옆에는 두지 않는다.
**길찾기**: 상세에만(목록 카드에는 지도 점만).

## 2. 단계 제안

| 단계 | 내용 | 볼 수 있는 일자리 |
|---|---|---|
| **1단계(권장 시작)** | 제한 없는 데이터만: 나라일터 + 잡알리오 + 서울 일자리포털 + 경기 잡아바 + 정부지원일자리 | 전국 공공 일자리 + **서울·경기는 민간 포함** |

| 2단계 대안 | 허락을 못 받으면 다른 시도 일자리센터 공개 데이터를 하나씩 찾아 추가(부산·인천 등 — 아직 조사 안 함) | 지역별로 늘림 |

1단계만으로는 '내 근처 알바'가 서울·경기 밖에서 약하다. 그래서 첫 화면 문구를 '공공·지역 일자리' 중심으로 하고, 지역마다 건수가 적으면 반경을 넓혀 보여 준다.

**공고 상세 색인 규칙**: 공고는 몇 주 만에 끝난다. 모집 중일 때만 사이트맵에 넣고 `validThrough`(마감일)를 단다. 마감 뒤에는 '마감된 공고' 표시와 같은 기관·동네 공고 링크를 남기고 noindex로 바꾼다. 30일 뒤에는 410을 준다. 오래 남는 검색 유입은 지역·기관 페이지가 맡는다. 구글 채용 검색(JobPosting) 기능이 한국에서 보이는지는 미확인이라, 스키마는 넣되 효과는 기대하지 않는다.

## 4. 만드는 방식

- **수집** `scripts/collect-job.py` + Actions `job-collect.yml`(하루 2~4번 — 공고는 날마다 바뀜): 출처별 목록 → 근무지 주소 → 시군구 코드(weather `regions.json`, 일반구는 시 코드) → 좌표(카카오, 30일 재확인 규칙, 새 주소만) → 마감 지난 것 제거. 호출 수는 표본 뒤 계산.
- **거르기**: 최저임금 미달로 보이는 시급, 업체명 없는 공고, 성인·유흥 관련 낱말 공고는 싣지 않는다(직업정보제공사업자 준수사항과 애드센스 정책).
- **저장**: 모집 중 공고가 수만 건 이하면 JSON 내장(약국 방식), 넘으면 D1(병원 방식) — 표본 뒤 결정.
- **앱** `apps/job`(Next 정적: 첫 화면·지역·공공·기관·안내) + Worker `guidejung-job`(`/api/near`·`/api/search`·`/api/where`·`/api/status`, 상세 `/job/*`, 사이트맵 묶음). CSS 접두어 `jb-`, 색(안) 보라 #6d28d9.
- **배포** `job-deploy.yml`(push·수집 후·수동). 첫 배포·도메인 연결은 승인 후.
- **개인정보**: 채용 담당자 이름·개인 휴대폰은 싣지 않는다. 기관 대표 전화와 원문 링크만 싣는다. 지원은 원래 공고 사이트에서 한다(우리는 이력서를 받지 않는다).

## 5. 법·정책 확인 (시작 전)

1. **직업정보제공사업 신고(직업안정법 제23조)**: '컴퓨터통신 등으로 구인·구직 정보를 제공하는 사업'은 고용노동부장관에게 신고하게 되어 있다. 공공 공고를 다시 보여 주는 우리 사이트도 해당할 가능성이 있다(미확인). 신고했다면 사이트에 신고번호를 표시해야 한다. 최저임금 미달 구인정보는 게재 금지다. **관할 고용노동지청에 해당 여부를 문의**한다. 접수처·서식은 이번 조사에서 확인하지 못했다.
2. **워크넷 상업적 이용**: 한국고용정보원에 광고가 붙은 무료 사이트에서 써도 되는지 문의한다(1장).
3. **애드센스**: 일자리 사이트 자체는 문제없다. 다만 '고수익 알바' 같은 문구, 유흥·다단계로 보이는 공고는 거른다.

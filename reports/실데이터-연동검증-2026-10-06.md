# TourAPI 실데이터 연동 검증

- 공식 TourAPI 실호출 성공: 관광지 20건, 축제 10건.
- 당일 행정표준코드 법정동 원장 다운로드 후 지역코드·주소·좌표 범위·축제 날짜 검증 통과.
- 별도 로컬 PostgreSQL 17.11 사용: localhost:55432. 기존 사이트 및 외부 서버 변경 없음.
- 전용 DB 백업을 별도 임시 DB에 복원하고 지역·장소·프로필·행사·RAW 테이블 건수 대조 통과.
- API 회귀 검사 12개 통과. 실제 데이터 검색·상세·축제·모바일 브라우저 검사 통과.
- 인증키와 로컬 DB 자격증명, RAW, 백업은 Git 제외. 인증키 로그 출력 없음.

현재 범위는 표본 30건이다. 전국 전체 수집 완료를 뜻하지 않는다. 원천 데이터 수집과 실제 방문 조건의 내용 검수는 구분하며 무료·아이 동반·반려동물·실내 조건은 확인 근거 없으면 미확인으로 표시한다. 공간 경계 검수와 내용 검수 전에는 SEO 색인을 허용하지 않는다.

배포 및 도메인 연결은 사용자 최종 확인 후 직접 수행한다. 증분 삭제 동기화, 대규모 공간 인덱스 조회, 운영 컨테이너 검증 및 향후 서비스 확장은 별도 작업이다.

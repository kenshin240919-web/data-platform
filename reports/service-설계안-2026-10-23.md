## 1. 클릭·체류 설계 (최우선)
1. **3초 답**(메인 맨 위): "📍 내 주변 1km 안 카센터 N곳 · 지금 영업 중 N곳 — 가장 가까운 곳 ○○모터스 300m (종합정비)". 위치 허용 전에는 접속 지역 기준.
2. **"무엇이 고장 났어요?" 칩**: 엔진오일·타이어·사고 수리(판금·도장)·검사·전기차·에어컨 → 누르면 그 일을 하는 업종(종합/소형/전문)으로 거르고 거리순. 원본에 세부 품목이 없으면 업종 기준으로만(과장 금지).
3. **정비 종류 설명 카드**: "종합정비업(1급)은 큰 사고 수리까지, 소형(2급)은 승용차 일반 정비, 전문정비는 타이어·오일 같은 한 가지" → 처음 오는 사람이 오래 읽는 콘텐츠.
4. **지역·조건 페이지**: `/region/{시군구}`(정비소 수·종류별 수), `/region/{시군구}/{종합|소형|전문}`(3곳 이상만), 검사소 페이지.
5. **상세 → 다음 클릭**: 정비소 상세에 주소·전화·종류·등록일(오래된 곳 표시)·길찾기·근처 다른 정비소 6곳·근처 주차장(parking)·주유소(oil)·충전소(charge)·검사소.
6. **브랜드 안내 페이지**(`/brand/{이름}`): "삼성전자서비스: 대표 번호, 출장 접수, 센터 찾기(공식) →" + "근처 다른 서비스: 휴대폰 → …" + FAQ. 다른 내근처 사이트에서 오는 길 최소화(내용이 적은 페이지).
7. **사이트 간 순환**: oil(주유소 상세 '근처 카센터'), parking, charge, traffic(휴게소 정비 시설), hospital은 연결 안 함(맥락 다름).

## 2. 데이터 (확인할 것)
- **전국자동차정비업체표준데이터(15028204)**: 지자체별 파일을 표준으로 묶은 데이터. 주차장처럼 전국 오픈API가 있는지, 항목(업체명·종류·주소·전화·영업상태·좌표·운영시간)·건수는 **활용신청 후 표본으로 확인**. 좌표가 없으면 카카오 좌표 변환(`KAKAO_REST_KEY`, 학원 사이트와 같은 방식).
- **경기도 자동차정비업체 현황(15057957)**: 위도·경도 포함으로 안내됨 — 전국 데이터가 부족하면 보조.
- **자동차 검사소**: 한국교통안전공단 데이터셋은 총량·접수 현황 위주로 보였고, 위치 목록은 미확인 → 공공데이터포털에서 '자동차검사소'·'지정정비사업자' 검색 후 결정.
- 영업 중 여부: 원본에 운영 시간이 없을 가능성이 큼 → 없으면 '지금 영업 중' 표시는 하지 않음(추정 금지), 전화 확인 안내.

## 3. 구조 (주차장 사이트와 같은 방식)
- 수집 `scripts/collect-service.py` + Actions `service-collect.yml`(매일) → 건수가 수만 곳이면 JSON 내장, 10만 곳 가까우면 D1(병원 방식).
- `apps/service`: Next.js 정적(메인·지역·지역×종류·검사소·브랜드 안내·안내 3종·sitemap·rss) + Worker `guidejung-service`(`/api/near`·`/api/search`·`/api/where`·`/api/status`, 상세 `/center/{id}`, `AutoRepair` JSON-LD).
- 배포 `service-deploy.yml`·도메인 연결은 **사용자 승인 후**.

# oil.guidejung.com 설계안 (2026-10-21)

> 공통 원칙: `reports/서비스-공통원칙-클릭체류.md`, CLAUDE.md SEO·GEO·AEO 원칙. 이름: **내근처 주유소** — 부제 "기름값 제일 싼 곳 어디?"(10/21 사용자: 주소 oil.guidejung.com).

## 1. 클릭·체류 설계 (최우선)
질문: **"내 주변에서 기름 제일 싼 곳?"**, "우리 동네 평균보다 얼마나 싸?", "경유 싼 곳?"
1. **3초 답**(메인 맨 위): "📍 내 주변 3km 안 휘발유 가장 싼 곳 ○○주유소 1,8xx원 · 1.2km — 전국 평균보다 70원 싸요(60L 가득 4,200원 절약)". 휘발유/경유 버튼으로 바로 바꿈. 위치 허용 전에는 접속 지역 기준.
2. **절약 금액**: 모든 목록에 "평균 대비 −○○원", 상세·지역 3초 답에 "60L 가득 ○원 절약" → 클릭 동기.
3. **순위·비교 입구**: 전국 최저가 TOP 10, 시도 평균 표(싼 순), 평균이 싼 시군구 TOP 8, 경유 시도별 최저가.
4. **상세 → 다음 클릭**: 주유소 상세에 시군구 순위·평균 대비·길찾기(카카오맵)·근처 다른 싼 주유소 6곳·지역 최저가 목록.
5. **사이트 간 순환**: 고속도로(휴게소 기름값·가까운 노선), 충전소(전기차 비교), 날씨·여행(가는 길) — `linksNear`. 헤더에 '휴게소 기름값 ↗'.

## 2. 데이터 (오피넷 무료 API, 10/21 표본)
- **하루 300회 한도**(키 화면 '호출건수/호출가능건수') → 방문자 요청마다 호출 불가. 매일 07:13 KST Actions `oil-collect.yml`이 `scripts/collect-oil.py`로 약 270회 호출해 `apps/oil/data/oil.json` 커밋.
- 호출: 전국 평균(`avgAllPrice`)·최근 7일(`avgRecentPrice` 휘발유·경유)·시도 평균(`avgSidoPrice` 2) → 시군구 평균 휘발유(`avgSigunPrice` 17) → **시군구별 휘발유 최저가 20곳(`lowTop10` 약 230)** → 시도별 경유 최저가 20곳(17) → 남으면 시군구 평균 경유(17). 지역 코드(`areaCode` 18회)는 매달 1일에만.
- 전체 주유소 목록 API는 없음 → 최저가 목록에 든 주유소(첫 수집 3,810곳)만. 셀프 여부는 이름으로.
- 좌표는 KATEC(Bessel TM) → WGS84로 수집 때 변환(오피넷 예시 좌표 → 강남 역삼동 확인).
- 최저가 목록에서 빠진 주유소도 **60일 동안 상세 페이지 유지**(마지막 확인 가격·날짜 표시) — 검색에 올라간 주소가 깨지지 않게.
- 한도를 다 못 쓴 날(첫날 23곳 건너뜀)은 그 지역의 어제 목록을 그대로 씀.

## 3. 구조
- `apps/oil`: Next.js 정적(메인·`/region`·`/region/{오피넷 시군구코드}`·`/diesel`·`/diesel/{시도코드}`·`/station/{주유소ID}`·안내 3종·sitemap·rss) + Worker `guidejung-oil`(`/api/near`·`/api/where`·`/api/status`, oil.json을 텍스트로 넣고 첫 요청 때 해석). D1·KV·Secret 없음.
- 배포: GitHub Actions `oil-deploy.yml`(wrangler, 토큰 github-d1). **사용자 승인 후** 자동 배포 트리거·도메인 연결.

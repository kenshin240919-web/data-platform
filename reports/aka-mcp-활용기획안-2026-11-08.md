# mcp.aka.page(다이소·편의점·영화관 MCP) 활용 기획안 — 2026-11-08 (2판)

> **결론**: 사용자 지정 새 사이트 3개 — **내근처 영화관**(지금 상영작·시간표·남은 좌석), **내근처 다이소**(자주 찾는 상품 매장 재고), **내근처 올리브영**(자주 찾는 상품 매장 재고) — 를 만든다. 순서는 **영화관 → 다이소 → 올리브영**. 영화관은 공식 데이터(영화진흥위원회 KOBIS·LOCALDATA 영화상영관)로 정적 페이지를 만들 수 있어 가장 안전하고, 올리브영은 오늘 시험에서 중계가 계속 502 오류라 마지막.
> 공통 조건: aka.page는 **다이소·편의점·영화관 내부 API를 분석해 다시 부르는 개인 오픈소스**라서 ① 재고·좌석 숫자는 저장·정적 HTML·사이트맵·JSON-LD에 넣지 않고 ② 방문 때만 불러오며 ③ 운영자에게 먼저 알린다.

## 1. 클릭·체류 설계 (맨 앞)

| 사이트 | 3초 답 (첫 화면) | 다음 클릭 (체류) |
|---|---|---|
| 🎬 내근처 영화관 | **지금 바로 볼 수 있는 영화** — "📍 김포 근처 30분 안 시작 4편 · CGV 김포한강 15:55 치이카와 87석 남음" | 영화 칩 → 같은 영화 다른 극장·시간 → 극장 페이지(주차장·근처 맛집) → 예매(공식 사이트) |
| 🧺 내근처 다이소 | **"김포시 다이소 14곳 중 9곳에 핫팩 있어요 · 가장 가까운 풍무로점 19개"** | 상품 칩(이번 주 자주 찾는 10개) → 다른 크기·종류 → 매장 안 **진열 위치**(예: 2층 ○구역) → 길찾기 |
| 💄 내근처 올리브영 | **"선크림 ○○ 근처 3곳에 있어요 · 오늘의 특가 5개"** | 상품 칩 → 매장 재고 → 오늘의 특가 → 공식 상품 페이지 |

- 공통: 위치 하나로 바로 결과(`useMyPosition` → 시군구 이름 `pickArea`/`nearest`), 상품·영화 칩을 누를 때마다 같은 동네 결과가 바로 바뀜, 다른 내근처 사이트로 이어지는 연결 카드.
- 클릭은 콘텐츠로만, 광고 근처 유도 문구 없음(애드센스 정책).

### 공식 데이터 (영화관용, 2026-11-08 확인)
- **KOBIS 오픈API**(영화진흥위원회 영화관입장권통합전산망): 일별·주간 박스오피스, 영화 목록·상세(감독·배우·등급·개봉일·장르). 응답 확인(키 없이 부르면 '유효하지 않은 키' → 서버 정상). **키 발급 필요**(무료, kobis.or.kr 회원가입 → 키 발급).
- **LOCALDATA '문화_영화상영관'**: 전국 지자체 영화상영관 인허가 정보(파일 `file.localdata.go.kr/file/movie_theaters/info`에 데이터셋 안내 페이지 확인 — 실제 CSV 내려받기 주소·칸은 다음 단계에서 확인). 극장 이름·주소·좌표·상영관 수 → **정적 극장 페이지**를 공식 데이터로 만들 수 있음.

## 4. 사이트 3개 (사용자 지정, 필수)

### 4-1. 🎬 내근처 영화관 (1순위)
- 이름(안) **내근처 영화관 · "지금 뭐 볼 수 있어?"** · `movie.guidejung.com`(안).
- **정적(공식 데이터, SEO·GEO·AEO)**:
  - `/` 3초 답 `NowShowing`(내 주변 극장 3~5곳 오늘 남은 상영, '30분 안 시작'·'좌석 넉넉'·'오늘 마지막 회차' 칩)
  - `/boxoffice`(KOBIS 어제 박스오피스 TOP 10·주간·관객 수 — 매일 수집 커밋), `/film/{KOBIS 영화코드}`(감독·배우·등급·개봉일·누적 관객 + '내 주변 오늘 상영' 실시간 칸 + Movie JSON-LD·FAQ)
  - `/region/{시군구}`(그 동네 극장 목록 — LOCALDATA), `/theater/{id}`(주소·상영관 수·주차장·근처 맛집·대중교통 + 오늘 시간표 실시간 칸, MovieTheater JSON-LD)
  - `/now`·`/kids`(전체관람가)·`/late`(심야 22시 이후)·`/morning`(조조 10시 이전) — 상황 페이지(안내는 우리 글, 목록은 실시간)
- **실시간(aka.page, 저장 안 함)**: CGV·롯데·메가박스·디트릭스 시간표·남은 좌석. 예매는 각 극장 공식 페이지로 연결(우리는 예매하지 않음).
- 연결: 여행(비 오는 날 실내·주말), 날씨(강수 60%↑ 주말 띠), 주차장, 맛집(여행 food), 모아보기 카드.
- 사용자 준비: **KOBIS 오픈API 키**, GA·Clarity ID.

### 4-2. 🧺 내근처 다이소 (2순위)
- 이름(안) **내근처 다이소 · "그거 다이소에 있어?"**(또는 3장 대안 이름) · 주소는 사용자 결정.
- **자주 찾는 상품 고르기**: ① 네이버 검색어 트렌드(이미 쓰는 NAVER API HUB 데이터랩)로 '다이소 ○○' 후보 60개의 주간 관심도 → 이번 주 TOP 10 ② 계절표(11~2월 핫팩·방한, 장마 우산·제습, 2~3월 새 학기 문구, 3·9월 이사 수납, 여름 휴가 캠핑·물놀이) ③ GA `stock_click` 많이 누른 상품. 매주 월 Actions가 상품 ID만 갱신(재고 숫자는 저장 안 함).
- 화면: `/` 3초 답 `NearDaiso`(이번 주 TOP 10 칩 → 시군구 매장별 재고 가까운 순, 비공개 수량은 '?' + 전화), `/item/{slug}`(우리 글: 종류 비교·고르는 법·FAQ, 숫자 없음 + 실시간 칸), 매장 상세는 만들지 않고 진열 위치·길찾기를 카드 펼침 안에.
- 연결: 날씨(우산·마스크), 겨울 차 관리(성에 제거제), 동물병원(배변패드), 수능·새 학기 시기 페이지.

### 4-3. 💄 내근처 올리브영 (3순위 — 중계 정상 확인 뒤)
- 이름(안) **내근처 올리브영 · "그 제품 근처 매장에 있어?"**(또는 대안 이름).
- 자주 찾는 상품: 네이버 검색어 트렌드 '올리브영 ○○' + 오늘의 특가(aka.page `get_catalog`, 오늘은 경로 404 — 다시 확인).
- 화면: 3초 답(인기 상품 칩 → 근처 매장 재고), '오늘의 특가' 칸, 상품 페이지는 공식 페이지로 연결. 화장품 효능 문구·순위 평가는 쓰지 않음(화장품법 광고 규정 — 사실만).
- 시작 조건: 올리브영 중계가 1주 동안 정상(운영자 상태 페이지·우리 `/api/status`로 확인).

## 6. 공통 기술 구조
- Worker는 사이트마다(`guidejung-movie` 등) `/api/now|stock|where|status`, aka.page 호출은 Worker 안에서만 + `caches.default` 10분 + `*.guidejung.com` Origin만. 실패·느림(6초)이면 부분 결과.
- 상품 표 `ITEMS`(slug → 다이소 상품 ID·올리브영 상품 코드·편의점 검색어)만 저장. 매주 갱신.
- 정적 데이터: 영화관만(KOBIS 박스오피스·영화 상세, LOCALDATA 극장) — 수집 Actions `movie-collect.yml` 매일.
- 개인정보 안내: '시군구 이름(또는 약 2km 칸 중심)과 상품만 외부(daiso-mcp)로 보냄' 추가.
- GA 이벤트 `stock_view`·`stock_click`·`showtime_click`(예매 연결) → ga-weekly 표에 열 추가.

## 8. 사용자 결정 필요
1. 다이소·올리브영 **이름·주소에 브랜드를 넣을지**(그대로 + '비공식' 표시 / 대안 이름) — 권장: 주소는 브랜드 없이, 화면 제목에 브랜드
2. 다이소·올리브영을 **사이트 2개로 나눌지, '내근처 재고' 한 사이트로 합칠지** — 권장: 합침(색인·신뢰가 한곳에 모임). 사용자가 나누기를 원하면 그대로 진행
3. 0단계 운영자 알림 — 권장: 함
4. 편의점(A)을 다이소와 함께 시작할지 — 권장: 함
5. 영화관 시작용 **KOBIS 키·GA·Clarity ID**

## 2. 사이트별 설계

### 2-1. 🏪 내근처 편의점 — "약국 닫았을 때, 급할 때"
- 이름(안) **내근처 편의점 · "밤에도 상비약 어디서?"**
- **왜 1순위**: 공식 데이터가 크고(42,023곳) 앱 활용신청도 필요 없으며, 내근처 수익 1·2위인 병원·약국 사이트(밤 방문)와 바로 이어짐.
- **정적 데이터** — LOCALDATA `건강_안전상비의약품 판매업소`(`file.localdata.go.kr/file/download/over_the_counter_medicine_stores/info`, CSV cp949, 활용신청 불필요). 2026-11-08 받음: 전체 92,415행 · **영업 중 42,023곳 · 좌표 39,244곳**(EPSG:5174 → 휴식 사이트 `tm5174`로 변환), 상호 기준 CU 16,290 · GS25 11,632 · 세븐일레븐 5,868 · 이마트24 1,291 · 미니스톱 333 · 기타 6,609. 상비약 판매자 등록 요건은 24시간 연중무휴 점포로 알려져 있음(약사법 제44조의2 — **법령 원문 확인 후 화면 문구에 사용**).
- **페이지**:
  - `/` 3초 답 `NearCvs`(내 주변 상비약 판매 편의점 가까운 순, 근처 약국 지금 문 연 곳 수 함께 — 약국 `/api/near`)
  - `/region/{시군구}`·`/region/{코드}/{cu|gs25|seven|emart24}`(3곳 이상), `/store/{id}`(Worker: 주소·전화·브랜드·지도·근처 지금 문 연 약국·가장 가까운 응급실·주차장, ConvenienceStore JSON-LD·FAQ), `/medicine`(상비약이 뭔지·살 수 있는 시간·나이 제한 등 법령 안내 — 우리 글, 출처 링크)
  - 실시간 칸: 상품 칩 → aka.page 재고(가까운 매장 3~5곳)
- **실시간 시험(11/8)**: 세븐일레븐 '타이레놀' 김포 → 상품 '타이레놀정500mg 8정 4,200원', 100곳 중 2곳 재고(구래메인점 16개), 22초. **GS25·CU는 같은 시각 중계 502·시간 초과**(6개를 동시에 불러 중계 한도에 걸렸을 수 있음, 원인 미확인), 이마트24는 매장 조건 형식 오류(지역 이름으로 다시 시험 필요). → 실시간은 '되면 보여 주는' 덤, 사이트 뼈대는 공식 데이터.
- 복용법·추천 문구는 쓰지 않음(사실·위치만).
- 연결: 약국(첫 화면·상세 '약국이 닫으면 → 상비약 편의점'), 병원·응급실, 날씨(비 → 우산 재고), 모아보기 카드, 알림('일·공휴일 약국' 알림에 편의점 한 줄).

### 2-2. 🎬 내근처 영화관 — "지금 뭐 볼 수 있어?"
- **정적 데이터**:
  - LOCALDATA `문화_영화상영관`(`.../file/download/movie_theaters/info`): 영업 중 3,489행(상영관 단위) → 같은 주소로 묶어 **805곳**(CGV 214 · 롯데시네마 147 · 메가박스 140 · 씨네Q 3 · 기타 294 — 독립·작은 영화관 포함), 좌표 있음.
  - **KOBIS 오픈API**(영화진흥위원회, 무료 키): 일별·주간 박스오피스, 영화 목록·상세(감독·배우·등급·개봉일·장르). 키 없이 부르면 '유효하지 않은 키' 응답 → 서버 정상 확인. **사용자 키 발급 필요**.
- **페이지**: `/`(3초 답 `NowShowing`: 내 주변 극장 3~5곳 오늘 남은 상영, 칩 '30분 안'·'좌석 넉넉'·'오늘 마지막 회차'·'아이와(전체관람가)'), `/boxoffice`(어제 TOP 10·주간·관객 수, 매일 수집), `/film/{KOBIS 코드}`(영화 정보 + '내 주변 오늘 상영' 실시간 칸, Movie JSON-LD·FAQ), `/region/{시군구}`, `/theater/{id}`(주소·상영관 수·주차장·근처 맛집 + 오늘 시간표, MovieTheater JSON-LD), 상황 페이지 `/now`·`/kids`·`/late`(22시 이후)·`/morning`(10시 전).
- **실시간 시험(11/8)**: CGV 김포한강 시간표·남은 좌석 1.1초, 롯데 김포공항 9~15초(관·예매 좌석까지), 메가박스 검단 8.7초, 극장 찾기는 메가박스 16초 → **극장 위치는 공식 데이터로**, 실시간은 시간표·좌석만, 극장 3곳을 동시에 불러 먼저 온 것부터.

- 연결: 여행(비 오는 날 실내·주말), 날씨(강수 60%↑ 주말 띠 '🎬 지금 볼 수 있는 영화'), 주차장, 맛집, 모아보기, 알림('🎬 이번 주 개봉작' 목요일).

### 2-3. 🧺 내근처 재고 — 다이소·올리브영 (탭 2개)
- 이름(안) **내근처 재고 · "그거 근처 매장에 있어?"** — 페이지 제목엔 '다이소 핫팩 재고'·'올리브영 선크림 재고'처럼 설명으로만 브랜드 사용, 화면 맨 위·푸터에 **"다이소·올리브영과 관계없는 비공식 안내"**, 로고·색은 쓰지 않음.
- **자주 찾는 상품**: 네이버 검색어 트렌드(이미 쓰는 NAVER API HUB 데이터랩)로 '다이소 ○○'·'올리브영 ○○' 후보 각 60개의 주간 관심도 → 이번 주 TOP 10 + 계절표(겨울 핫팩·방한, 장마 우산·제습, 새 학기 문구, 이사 수납, 여름 캠핑) + GA 클릭 수. 매주 월 Actions가 **상품 ID만** 갱신(재고 숫자 저장 안 함).
- **페이지**: `/`(탭 + 3초 답), `/daiso/{상품}`·`/oliveyoung/{상품}`(우리 글: 종류 비교·고르는 법·FAQ 2,000자 이상 + 실시간 칸, 숫자는 정적에 없음), `/region/{시군구}`(실시간 칸 + 연결 카드). 매장 상세 페이지는 만들지 않음(매장 데이터가 공식 공개 데이터가 아니라서) — 카드 펼침 안에 진열 위치·전화·길찾기.
- **실시간 시험(11/8)**: 다이소 정상(핫팩 '일반 2개입' 김포 14곳 — 있음 8·0개 1·수량 비공개 5, 약 1.3초, **위도·경도는 무시돼 시군구 이름으로 불러야 함**). **올리브영은 매장·재고 4번 모두 502(중계 오류)** → 올리브영 탭은 1주 정상 확인 뒤 열기.
- 화장품 효능·순위 평가 문구는 쓰지 않음(사실만). 추가 기능: '한 번에 장보기'(고른 3개가 다 있는 가장 가까운 매장), 다이소 진열 위치.

## 3. 공통 구조
- 각 사이트 Worker(`guidejung-cvs`·`guidejung-movie`·`guidejung-stock`): `/api/near|search|where|status` + aka.page 중계 `/api/live`(Worker 안에서만 호출, `caches.default` 10분으로 같은 지역·상품 요청 합침, 6초 넘으면 부분 결과, `*.guidejung.com`만).
- 위치: 서버엔 칸 중심·시군구 이름만(`useMyPosition`·`pickArea`·`nearest`), 거리는 휴대폰에서(`fixKmNow`·`here`), 목록은 `padKm`·`padLimit`.
- 수집 Actions: `cvs-collect.yml`(매일, LOCALDATA), `movie-collect.yml`(매일, LOCALDATA + KOBIS), `stock-items.yml`(매주, 상품 ID만). 배포는 기존처럼 `*-deploy.yml`.
- 공통 부품 그대로: NetworkBar·GA·Clarity·애드센스·어두운 화면·PWA·공유·즐겨찾기·seo.tsx·llms.txt·IndexNow 키·assetlinks·`SITES` 연결 바(첫 배포 뒤 자동 공개).
- GA 이벤트 `live_view`·`live_click`·`showtime_click` → ga-weekly 열 추가.

## 4. 위험과 대응

| 위험 | 대응 |
|---|---|
| aka.page는 다이소·편의점·극장 **내부 API를 다시 부르는 개인 프로젝트**(공식 제휴 아님). 약관상 자동 수집·재배포 금지 가능성, 데이터베이스권(저작권법 제93조) 소지 — **약관 원문 미확인** | 실시간 숫자는 저장·정적 HTML·사이트맵·JSON-LD에 넣지 않음, 출처 표시. 정적 페이지는 공식 데이터·우리 글만 |

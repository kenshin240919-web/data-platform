## 0. 클릭·체류 설계 (가장 먼저)

**3초 답(첫 화면 맨 위)**: "📍 ○○구에서 받을 수 있는 혜택 **N가지** — 이번 달 마감 **M건**"
- 위치는 `useMyPosition()` 칸 중심 → 가장 가까운 시군구(weather `regions.json`). 서버로는 칸 중심만.
- 위치가 없으면 접속 위치(`/api/where`), 그것도 없으면 시도 버튼.

**다음 클릭을 부르는 장치**
1. **3문항 맞춤 찾기**: 나이 → 가구(임신·영유아·학생 자녀·어르신·1인) → 해당 사항(장애·보훈·한부모·무주택·구직·소상공인·농어업). 결과는 "나에게 맞을 수 있는 혜택 N가지"와 금액 큰 순. 답은 브라우저 안에서만 쓴다(localStorage `gj.benefit`, 서버 전송 없음).
2. **마감 임박 D-day**: 신청기한에 날짜가 있는 773건(7%)과 월 단위로 적힌 것("2026.10월중")을 해석해 '이번 주·이번 달 마감'을 보여 준다.
3. **많이 찾는 혜택**: 원본 `조회수`로 줄 세운다(예: 근로·자녀장려금 2,434,796회). 시군구별, 전국별로 나눈다.
4. **오늘 새로 생기거나 바뀐 혜택**: `수정일시`·`등록일시`가 매일 바뀐다(최근 30일 수정 2,257건). 우리 동네 것은 위로 올린다.
5. **🔔 알림 주제 추가**: '우리 시군구 새 혜택 · 마감 3일 전'. near 웹 푸시에 주제만 더한다.
6. **신청 준비물 → 내근처 서류**: 구비서류에 자주 나오는 것(통장 1,688·신분증 1,654·가족관계증명서 1,074·주민등록등본 940·소득금액증명 101)을 서류 사이트 `/doc/{slug}`와 가까운 무인발급기·주민센터로 잇는다.
7. **상황 연결**: 임신·출산 → 병원 산부인과·소아과, 어르신 → 약국·병원, 소상공인 → 시장(온누리), 전기차 → 충전소, 농어업 → 날씨.
8. **시기 페이지**: 근로·자녀장려금(5월 정기·9월 반기), 에너지바우처·난방비(겨울), 새 학기 교육급여(2월 — 로드맵 6⑤와 합침), 연말정산(1월).

**광고**: 상세 2곳, 목록 1곳(다른 사이트와 같음). '신청하기'처럼 보이는 위치·문구 옆에는 두지 않는다.

## 3. 페이지 구조

| 주소 | 내용 | 색인 |
|---|---|---|
| `/` | 3초 답 · 맞춤 찾기 · 마감 임박 · 많이 찾는 혜택 · 분야 · 시도 | ✅ |
| `/find` | 3문항 맞춤 찾기(결과는 브라우저에서) | ✅(설명 정적) |
| `/region` · `/region/{시군구코드}` | 그 동네(시군구+시도+전국) 혜택을 분야·대상별로, 마감 임박, 많이 찾는 순 | ✅ |
| `/region/{코드}/{분야}` | 10건 이상일 때만 | ✅ |
| `/topic/{분야}` | 전국 분야별(임신·출산 등) | ✅ |
| `/deadline` | 이번 주·이번 달 마감 | ✅ |
| `/new` | 오늘 새로 생기거나 바뀐 혜택 | ✅ |
| `/b/{서비스ID}` | 혜택 상세: 누가·무엇을·얼마·언제까지·어떻게·준비물(서류 연결)·문의·근거 법령·정부24 링크·같은 동네 다른 혜택·FAQ·GovernmentService JSON-LD | 단계별 |
| `/search` | 검색 | noindex |

**상세 1만 쪽 색인 단계**(학원·병원과 같은 방식, Worker `SITEMAP_STAGE`): 1단계 조회수 상위·현금·마감 있는 것 약 3,000건 → 2단계 시군구 혜택 → 3단계 전체. 상세마다 '이 동네 같은 분야 혜택 N가지'와 준비물 연결로 고유 내용을 붙인다.

## 4. 만드는 방식

- **수집** `scripts/collect-benefit.py` + Actions `benefit-collect.yml`(매일 새벽, 약 33회 호출 — 한도 10,000의 0.3%): 목록·상세·지원조건을 합치고, 지역 코드·마감일(해석 가능한 것)·금액(최대값)·필요 서류 slug를 뽑는다. 건수가 20% 넘게 줄면 저장하지 않는다.
- **저장**: 요약 `apps/benefit/data/summary.json`(목록 카드용) + 상세는 **D1**(`guidejung-benefit`, 학원 방식). 상세 글이 길어(1만 건) Worker에 통째로 넣지 않는다.
- **앱** `apps/benefit`(Next 정적: 첫 화면·지역·분야·마감·새 소식) + Worker `guidejung-benefit`(상세·검색·`/api/near?region=`·사이트맵 묶음·`/api/where`).
- **배포** `benefit-deploy.yml`(push·매일 수집 후·수동). 첫 배포·도메인 연결은 승인 후.
- **지켜야 할 것**: 모든 페이지에 "공공기관이 아닌 민간 정보 서비스" 고지·출처(행정안전부)·확인 날짜, 신청은 정부24·접수기관 링크로만, 개인정보 수집 없음, 과장 문구 없음.

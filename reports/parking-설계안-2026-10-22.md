# parking.guidejung.com 설계안 (2026-10-22)

> 공통 원칙: `reports/서비스-공통원칙-클릭체류.md`, CLAUDE.md SEO·GEO·AEO 원칙. 이름(안): **내근처 주차장** — 부제 "여기 주차 어디 해?". 주소(안) `parking.guidejung.com`(사용자 확정 필요).

## 1. 클릭·체류 설계 (최우선)
질문: **"지금 여기(가려는 곳) 근처에 주차 어디 해?"**, "무료 주차장 있어?", "2시간 세우면 얼마야?"
1. **3초 답**(메인 맨 위): "📍 내 주변 1km 주차장 N곳 · 무료 N곳 — 가장 싼 곳 ○○공영주차장 350m · 30분 600원". 위치 허용 전에는 접속 지역(IP) 기준, 허용하면 정확 위치. 반경은 1→2→5km로 넓힘.
2. **"몇 시간 세울 거예요?" 요금 계산 칩**(30분·1시간·2시간·4시간·하루): 누르면 모든 카드의 요금이 그 시간 기준으로 바뀌고 싼 순 정렬. 기본시간·기본요금·추가단위 시간·추가단위 요금으로 계산(1일 최대 요금이 있으면 그 이하). 가장 강한 클릭 장치.
3. **조건 칩**: 무료 · 공영 · 24시간 · 토요일/공휴일 무료 · 장애인 전용 구획 · 카드 결제. 지역·조건 조합은 정적 페이지(`/region/{코드}/free` 등)로 검색 유입("강남구 무료 주차장").
4. **상세 → 다음 클릭**: 주차장 상세에 요일별 운영시간·요금표·시간별 예상 요금·길찾기(카카오맵)·근처 다른 주차장 6곳(더 싼 곳 먼저)·가까운 가볼만한곳/맛집(trip)·충전소(charge)·날씨.
5. **목적지에서 들어오는 길(사이트 간 순환, 효과가 가장 큼)**: trip 상세 4.9만 쪽·병원·학원·학교 상세의 '함께 보면 좋은 정보'에 "🅿️ 근처 주차장 N곳 · 가장 가까운 곳 ○○m" → 주차장 사이트로. 반대로 주차장 상세에서 주변 여행지·맛집으로.
6. **2단계 — 실시간 빈자리**(서울 시영 주차장 등 실시간 데이터가 있는 곳만): "지금 빈자리 N면" 색깔 표시. 실시간 데이터가 없는 곳은 표시하지 않음(빈자리 추정 금지).

## 2. 데이터
### 2-1. 1단계: 전국주차장정보표준데이터 (공공데이터포털 15012896)
- 지자체가 관리하는 공영·민영 주차장(노상·노외·부설), 거주자우선주차 제외. 월말 일괄 취합, 갱신 주기는 지자체마다 다름.
- 오픈 API `https://api.data.go.kr/openapi/tn_pubr_prkplce_info_api`(전체 목록, 페이지 단위). **10/22 표본 호출: `DATA_GO_KR_KEY`로 HTTP 403** → 이 데이터의 활용신청이 안 된 것으로 추정(활용신청 후 다시 시험).
- 표준 항목(공공데이터 개방 표준 기준, 표본으로 확인 예정): 주차장 관리번호·이름·구분(공영/민영)·유형(노상/노외/부설)·도로명/지번 주소·주차 구획 수·급지·부제 시행·운영 요일·평일/토요일/공휴일 운영 시각·요금 정보(무료/유료/혼합)·기본시간·기본요금·추가단위 시간·추가단위 요금·1일 주차권 요금·월 정기권 요금·결제 방법·특기사항·관리 기관·전화번호·위도·경도·장애인 전용 구획 여부·데이터 기준일.
- **미확인**(표본으로 확인): 전체 건수(수만 곳으로 추정), 좌표 채움 비율(빈 곳은 기존 카카오 좌표 변환 `KAKAO_REST_KEY`로 채움 — academy와 같은 방식, 새 주소만), 요금 칸 품질(0원·빈칸·문장형), 같은 주차장 중복, 하루 호출 한도.
- 원본 오류 대비: 요금이 비정상(예: 기본요금 0원인데 '유료')이면 계산하지 않고 "요금 확인 필요", 모든 화면에 "지자체 제공 정보, 현장 요금과 다를 수 있음 · 기준일 ○○" 표시.

### 2-2. 2단계: 실시간 빈자리 (나중에)
- 서울 열린데이터광장 '시영주차장 실시간 주차대수'(GetParkingInfo) — 별도 인증키(서울 열린데이터광장)와 허용 도메인 `openapi.seoul.go.kr` 필요. 요청 인자·응답 필드는 공식 명세로 확인 전(커뮤니티 코드만 확인).
- 그 밖의 지자체·한국교통안전공단 실시간 API는 **아직 확인하지 못함** → 1단계 공개 뒤 조사.

## 3. 구조 (hospital·academy와 같은 방식)
- 수집 `scripts/collect-parking.py` + Actions `parking-collect.yml`(주 1회 또는 매일 — 원천이 월 단위라 하루 1번이면 충분): 전체 목록 → 정규화(요금 숫자화, 운영시각, 시군구 코드는 weather `regions.json`과 같게) → 좌표 보강 → D1 적재(바뀐 행만, manifest) + `apps/parking/data/summary.json`(시도·시군구·조건별 건수, 대표 주차장 8곳씩) 커밋.
- 저장: 건수가 수만 곳이면 **D1 `guidejung-parking`**(Claude가 Actions로 생성 가능, 승인 후). 2만 곳 이하로 작으면 약국처럼 JSON을 Worker에 직접 넣고 D1 없이.
- `apps/parking`: Next.js 정적(메인·`/region`·`/region/{시군구코드}`·`/region/{코드}/free|public|24h`(해당 주차장 있는 곳만)·`/search`(noindex)·안내 3종·sitemap·rss) + Worker `guidejung-parking`(`/api/near`(위치·반경·조건·주차 시간 → 예상 요금 순)·`/api/search`·`/api/where`·`/api/status`, 상세 `/parking/{관리번호}`는 D1로 만들어 정적 틀에 채움, 사이트맵 묶음).
- SEO·GEO·AEO: 상세 `ParkingFacility` JSON-LD(주소·좌표·운영시간 `openingHoursSpecification`·요금 설명), 지역 페이지 FAQ("○○구 무료 주차장은 몇 곳?", "가장 싼 공영주차장은?"), Breadcrumb, llms.txt, robots(AI 크롤러 허용, Daum PIN 마지막 줄).
- 연결: `packages/ui/src/network.tsx`에 `SITES.parking`(처음엔 hidden → 라이브 확인 후 사용자 승인으로 공개), trip·hospital·academy·school 상세의 '함께 보면 좋은 정보'에 근처 주차장 링크(주차장 수 요약은 각 Worker가 `parking` Worker `/api/near`를 부르거나, 빌드 때 시군구 단위 건수만 사용 — 구현 때 비용 비교).
- 배포: GitHub Actions `parking-deploy.yml`(oil·hospital과 같은 방식, wrangler + 토큰 github-d1). **Worker 만들기·도메인 연결·자동 배포는 매번 사용자 승인 후 실행.**

## 4. 받을 것 (사용자)
1. **공공데이터포털 활용신청**: data.go.kr 로그인 → '전국주차장정보표준데이터' 검색(데이터 번호 15012896) → 오픈API 탭 → 활용신청(자동 승인으로 알려짐, 미확인). 같은 계정이면 기존 `DATA_GO_KR_KEY` 그대로 사용 → 승인 뒤 알려 주시면 표본(`parking-sample.yml`)을 다시 돌려 건수·좌표·요금 품질을 확인합니다.
2. **GA 측정 ID**(Google Analytics에 parking 속성·웹 스트림 등록 후 G-…)와 **Clarity 프로젝트 ID**.
3. 사이트 주소 확정(안: `parking.guidejung.com`)과 이름 확정(안: 내근처 주차장 · "여기 주차 어디 해?").
4. (2단계, 나중) 서울 열린데이터광장 인증키 → GitHub Secret, 허용 도메인 추가.

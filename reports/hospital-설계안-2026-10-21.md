## 1. 클릭·체류 설계 (최우선)
질문: **"지금 진료하는 ○○과 어디?"**(밤·주말·공휴일, 아이가 아플 때), **"근처 응급실 지금 자리 있어?"**.
1. **3초 답**: "📍 내 주변 지금 진료 중 소아청소년과 3곳 · 가장 가까운 ○○소아과 400m (19:00까지)". 과목 버튼(소아청소년과·내과·이비인후과·정형외과·피부과·안과·산부인과·치과·한의원)으로 바로 바꿈.
2. **🚑 응급실 카드**: 내 주변 응급실 가까운 순 + 실시간 응급실 남은 병상(`hvec`)·갱신 시각.
3. **상태 색깔**: 진료 중·곧 마감(30분)·마감 — 요일별 진료 시간으로 계산(약국과 같은 규칙, 공휴일 시간 따로).
4. **조건 칩**: 지금 진료 중 · 야간(평일 20시 이후) · 토요일 · 일요일 · 공휴일.
5. **롱테일 입구**: 시군구 × 과목 페이지 "강남구 소아청소년과 N곳 · 야간·주말 진료", 시군구 × 조건 "강남구 일요일 진료 병원".
6. **사이트 간 순환**: 병원 상세 → 근처 지금 문 연 약국(pharmacy), 날씨, 아이와 갈 곳(trip), 학교(school).

## 2. 데이터 (10/20~21 표본 `hospital-sample.yml`)
- 병·의원 **79,004곳**(5,000행/회, 좌표 모두). 표본 5,000곳: 한의원 1,816·의원 1,796·치과의원 839·보건소 227·병원 87·요양병원 77·한방병원 60·종합병원 45 …
- 요일별 진료 시간 `dutyTime1~8s/c`(8=공휴일): 일요일 있음 약 15%, 공휴일 약 17%, 평일 20시 이후 약 9%. 소개 `dutyInf`, 비고 `dutyEtc`, 응급실 운영 `dutyEryn`(1=운영).
- **진료과목은 목록에 없음** → 과목 코드 `QD`로 조회해 과목별 기관 목록을 모아 붙임(D001 내과 23,680곳·D002 소아청소년과 15,159·D005 피부과 17,527·D013 이비인후과 12,474·D008 정형외과 12,385·D022 가정의학과 10,531 …, 하루 약 50회 호출). 신고한 '진료과목' 기준이라 전문의 여부와는 다름 → 화면에 그렇게 안내.
- 응급실 실시간 가용병상 `ErmctInfoInqireService/getEmrrmRltmUsefulSckbdInfoInqire`(시도 `STAGE1`, 서울 50곳): `hvec` 응급실 병상, `hvidate` 갱신 시각 → Worker가 시도별 5분 캐시(KV).
- 명절 비상 진료기관: 요청 주소 미확인(다음 단계).

## 3. 구조 (학원 사이트 방식 + 약국 배포 방식)
- 크기(약 8만 곳·과목 포함)가 Worker에 넣기엔 커서 **D1**. `scripts/collect-hospital.py`(매일) → `scripts/build-hospital-d1.mjs`(바뀐 행만) → `apps/hospital/data/summary.json`(지역·과목 통계, 정적 페이지용) 커밋.
- Worker `guidejung-hospital`: `/api/near`·`/api/search`·`/api/er`(실시간 병상)·`/api/where`·`/api/status`, 상세 `/hospital/{hpid}`(`/hospital/shell` 틀), `/sitemap.xml` 묶음.
- 배포: GitHub Actions `hospital-deploy.yml`(wrangler, 도메인 `routes` custom_domain), Secret은 Actions가 `wrangler secret put`으로 넣음.

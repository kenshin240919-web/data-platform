## 0. 클릭·체류 설계 (가장 먼저)

**3초 답(첫 화면 맨 위)**: 위치 하나로
- 🏢 **가장 가까운 주민센터 · 지금 대기 N명**(민원실 실시간 대기 API에 있는 곳만, 없으면 거리·평일 09~18시 안내)
- 🖨️ **지금 쓸 수 있는 무인민원발급기 N대**(평일·공휴일 운영 시간으로 '지금 운영 중' 계산, 24시간 기기 먼저)
- 📮 가장 가까운 우체국 · 🛂 여권 만드는 곳(여권사무대행기관)

**계속 누르게 만드는 흐름**
1. 첫 화면 → "**어떤 서류가 필요하세요?**" 칩(주민등록등본·초본·가족관계증명서·건강보험 자격득실·토지대장 등, 발급기 데이터의 `발급제증명` 이름 그대로) → 그 서류를 **지금 뗄 수 있는 가까운 발급기**만 목록.
2. 발급기·주민센터 상세 → 운영 시간표(오늘 강조), 뗄 수 있는 서류 전체, 장애인 편의 기능(점자·음성·휠체어), 근처 다른 발급기·우체국·주차장(🅿️ 연결)·약국.
3. "**밤·주말에 서류 떼기**" 페이지: 지금 운영 중인 24시간·주말 발급기만.
4. 서류별 페이지 `/doc/{서류}`: "온라인(정부24)으로 되는지 / 발급기에서 되는지 / 꼭 방문해야 하는지" 답 + 내 주변 뗄 수 있는 곳. 수수료 숫자는 공식 자료로 확인한 것만 적고, 확인 전에는 쓰지 않음.
5. 지역 페이지 `/region/{시군구}`: 주민센터 목록·발급기 수·24시간 발급기·우체국·여권 기관(검색 유입의 바닥).

**다른 내근처 사이트와 연결**: 주차장(주민센터 근처 주차), 약국·병원(서류 떼러 나간 김에), 학교(재학증명은 학교·정부24 안내), 날씨(가는 길 비 소식). 내근처 모아보기(near) 8카드에 '🖨️ 지금 쓰는 발급기' 추가 후보.

**광고**: 다른 사이트와 같은 자동광고 + 수동 2곳(목록 아래·상세 소개 아래). 공공기관 사이트로 오인될 표현(기관 로고·'공식' 표기) 금지 — "공공데이터로 만든 민간 안내 사이트" 고지.

## 5. 네이버 API (10/27 정정)
- 네이버 개발자센터(developers.naver.com) 검색 API는 **2026-07-31 신규 신청 종료**, 2027-06-30 기존 방식 종료 → 새 키는 **NAVER API HUB**(네이버 클라우드 플랫폼 콘솔 Services > Application Service > NAVER API HUB > 이용 신청 → 앱 등록, 사용할 API '검색 - 지역' 선택)에서만 받음. (처음엔 Claude가 개발자센터로 잘못 안내 — 사용자 지적으로 정정)
- 호출: `GET https://naverapihub.apigw.ntruss.com/search/v1/local?query=…&display=5`, 헤더 `X-NCP-APIGW-API-KEY-ID`·`X-NCP-APIGW-API-KEY`(HUB 앱의 Client ID/Secret — 계정 IAM 키는 401). **공식 문서(api.ncloud-docs.com/docs/naver-api-hub-search-local, 10/27 확인)**: `display` 1~5, `start`는 1만(다음 쪽 없음 → 한 검색어로 최대 5곳), `sort` random|comment(카페·블로그 리뷰 수 순), 응답 title·link·category·description·address·roadAddress·mapx·mapy(WGS84), **telephone은 값을 주지 않음**, 사진·리뷰·영업시간 없음. 검색 API **하루 25,000회**. 콘솔 메뉴: All Services > Application Services > NAVER API HUB > Application > [Application 등록] → API 선택 → 이름 → API 관리 [인증 정보]에서 Client ID/Secret. (guide.ncloud-docs.com은 이 클라우드(미국 IP)에서 접근 차단, api.ncloud-docs.com `.md`는 읽힘)
- 한도(2차 자료, 콘솔에서 확인 필요): 검색 통합 월 최대 775,000건·키당 50 RPS, **현재 한시적 무료·향후 유료 예고** → 유료 전환 공지가 나오면 사용자에게 먼저 알리고 끄거나 계속할지 결정.
- GitHub Secret 이름(안): `NAVER_HUB_CLIENT_ID`·`NAVER_HUB_CLIENT_SECRET`.

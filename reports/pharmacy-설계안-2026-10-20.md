## 1. 클릭·체류 설계 (최우선)
질문은 하나: **"지금 문 연 약국 어디?"** — 밤·주말·공휴일·명절에 급하게 찾음(검색 폭증일: 설·추석·연휴).

1. **3초 답**: "📍 내 주변 지금 문 연 약국 N곳 · 가장 가까운 곳 ○○약국 350m(22:00까지)". 위치 미허용이면 접속 지역 기준 + 위치 카드.
2. **상태 색깔**: 영업 중(초록)·곧 닫음(30분 안, 노랑)·닫힘(회색). 지금 시각·요일·공휴일 기준으로 브라우저에서 계산(데이터는 요일별 시작·끝 시각).
3. **필터 칩**: 지금 영업 중 · 밤 10시 이후 · 일요일 · 공휴일 · 24시간(심야).
4. **약국 카드**: 오늘 운영 시간, 전화 버튼, 길찾기(카카오맵), 요일별 시간표.
5. **롱테일 입구**: 시군구 페이지 "강남구 일요일 약국", "강남구 심야 약국", "강남구 공휴일 약국" — 정적 HTML에 실제 약국 이름·시간.
6. **명절 특집**: 설·추석 연휴 날짜별 문 여는 약국(공휴일 운영 시간 기준, 원본 '명절 당번'은 별도 데이터 확인 필요).
7. **사이트 간 순환**: 근처 병원(hospital, 소아과·야간), 날씨, 여행지(여행 중 약국), 고속도로 휴게소 근처 약국.

광고: 3초 답 아래 1곳, 목록 아래 1곳, 상세 하단 1곳(버튼과 간격).

- 시군구 페이지 title 예: "강남구 일요일·공휴일·심야 약국 N곳 | 내근처 약국".

## 3. 데이터 (활용신청 후 표본 확인 예정)
- `getParmacyListInfoInqire`(약국 목록): 시도 `Q0`·시군구 `Q1`·요일 `QT`·이름 `QN`, 페이지 단위. 응답 필드(문서 기준, **미확인**): 기관 ID `hpid`, 이름 `dutyName`, 주소 `dutyAddr`, 전화 `dutyTel1`, 요일별 시작·끝 `dutyTime1s~8s`/`dutyTime1c~8c`(1=월 … 7=일, 8=공휴일, 'HHMM'), 좌표 `wgs84Lat`·`wgs84Lon`.
- `getParmacyLcinfoInqire`(위치 기반): 좌표 주변 약국 — 실시간 '내 주변'은 정적 데이터로 계산하면 호출 불필요.
- **좌표가 원본에 있음**(카카오 변환 불필요, 미확인).
- **수집 방식**: 하루 1회 Actions로 전국 목록(페이지 수십 회) → 시군구별 정적 데이터 + Worker에 같이 넣기(학교 사이트처럼, 크기 확인 후 결정 — 크면 D1). '지금 영업 중'은 브라우저·Worker가 현재 시각으로 계산.
- 공휴일 판단: 한국천문연구원 특일 정보(공공데이터포털, 별도 활용신청) 또는 코드에 공휴일 표.

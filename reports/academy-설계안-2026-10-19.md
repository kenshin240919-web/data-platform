## 1. 클릭·체류 설계 (최우선)
학부모·학생의 질문은 거의 두 가지다: **"우리 동네에 어떤 학원이 있지?"** 와 **"학원비는 보통 얼마야?"**

1. **3초 답**: 첫 화면 맨 위 "📍 {동네} 학원 **N곳** · 수학 학원 평균 **월 OO만 원**" 한 줄 + 과목 버튼(수학·영어·국어·과학·논술·예체능·코딩).
2. **과목·학년 칩**: 초등/중등/고등 × 과목. 누르면 같은 화면이 바로 바뀜(목록을 계속 훑게).
3. **학원 카드**: 학원명·과목·대상·**공개 수강료(과정별)**·정원·거리. 카드마다 "같은 과목 근처 학원 비교" 버튼.
4. **비교**: 관심 학원 최대 4곳 담아 수강료·정원·교습과정 나란히 보기(브라우저 저장, 로그인 없음).
5. **순위·통계**: "{구} 과목별 평균 수강료", "학원 많은 동네 TOP 10", "이번 달 새로 개원한 학원".
6. **롱테일 정적 페이지**(검색 유입 입구): "{시군구} 학원"(약 250), "{시군구} {과목} 학원"(250 × 과목 7 ≈ 1,750), "{학원명} 수강료"(학원 상세, 수만 건).
7. **재방문**: 최근 본 동네·관심 학원, 다음 방문에 상단에 보여 줌.
8. **사이트 간 순환**: 학원 주변 날씨(weather 등하원 우산), 주말 아이와 갈 곳(trip `/kids`), 학원가 주차·충전소(charge).

광고: 3초 답 아래 1곳, 목록 중간 1곳, 상세 하단 1곳. 버튼·비교 조작부와 간격을 둠(애드센스 정책).

## 2. SEO·GEO·AEO 설계 (기본 원칙)
- 페이지마다 고유 title·description·canonical, `public/og.png`, `llms.txt`, robots.txt(AI 크롤러 허용·Daum PIN 마지막 줄), sitemap·RSS(새로 개원한 학원).
- JSON-LD: 레이아웃 `siteLd`, 하위 `breadcrumbLd`, 학원 상세는 schema.org `EducationalOrganization` + 과정별 `Course`(수강료가 공개된 경우 `offers`).
- **정적 HTML에 실제 숫자**: 지역·과목 페이지에 학원 수·평균/최저/최고 수강료·학원 이름 목록을 미리 넣음.
- **질문·답변(Faq)**: "관악구 수학 학원 평균 수강료는?", "중계동 영어 학원은 몇 곳?", "OO학원 수강료는 얼마인가요?" — 페이지 데이터로 답을 만듦.
- 주의: 수강료는 **교육청에 공개된 값·기준일**을 그대로 쓰고 "실제 수강료는 학원에 확인"을 붙임(AI 검색이 인용할 때 근거가 분명하도록).

### 3-1. 실호출 결과 (10/19, 인증키 없이)
- 키 없이는 **어느 쪽(pIndex)을 요청해도 첫 5건만** 응답 → 전체 수집은 인증키 필수.
- 시도교육청별 건수(`list_total_count`, 학원+교습소): 서울 B10 25,512 · 부산 C10 9,072 · 대구 D10 8,013 · 인천 E10 6,921 · 광주 F10 4,824 · 대전 G10 3,840 · 울산 H10 3,693 · 세종 I10 1,749 · 경기 J10 39,257 · 강원 K10 3,196 · 충북 M10 3,473 · 충남 N10 4,500 · 전북 P10 4,714 · 전남 Q10 3,470 · 경북 R10 5,763 · 경남 S10 8,746 · 제주 T10 1,766 → **합계 138,509건**(행 수, 3-0 참고).
- 응답 필드: `ADMST_ZONE_NM`(시군구)·`ACA_INSTI_SC_NM`(학원/교습소)·`ACA_ASNUM`(지정번호, id로 사용)·`ACA_NM`·`ESTBL_YMD`(개설일)·`REG_STTUS_NM`(개원 등)·`CAA_BEGIN_YMD`/`CAA_END_YMD`(휴원 기간 추정)·`TOFOR_SMTOT`(정원 합계)·`DTM_RCPTN_ABLTY_NMPR_SMTOT`(일시수용능력)·`REALM_SC_NM`(분야, 예: 입시.검정 및 보습)·`LE_ORD_NM`(계열)·`LE_CRSE_LIST_NM`(과정 목록)·`LE_CRSE_NM`(과정, 예: 보습)·`PSNBY_THCC_CNTNT`(인당 수강료)·`THCC_OTHBC_YN`(수강료 공개)·`BRHS_ACA_YN`(기숙학원)·`FA_RDNMA`/`FA_RDNDA`(도로명 주소·상세)·`FA_RDNZC`(우편번호)·`FA_TELNO`·`LOAD_DTM`(적재일).
- **좌표 없음 확인** → 주소→좌표 변환 필요.
- **수강료 형태 확인**: `과정명:금액, 과정명:금액`(예: `문법 영어:268000, 리딩:268000, 리스닝:192000`), 기간(월/주) 표기 없음. 표본 5건 중 2건만 값이 있고 나머지는 빈칸(공개 Y여도 비어 있음) → 비율은 전체 수집 뒤 확인.
- 전화번호에 `02-0000-0000` 같은 자리표시 값이 있음 → 표시하지 않음.
- **갱신**: 원본은 개원·변경·휴원·폐원 때 갱신된다고 함 → 하루 1회 GitHub Actions로 시도교육청 17곳 전체를 받아 바뀐 것만 반영(trip 자동 수집과 같은 방식).
- **좌표 변환**: 처음 한 번 전체(건수 미확인, 수만~10만 건 추정)를 변환하고, 이후엔 새 주소만. 무료 한도 안에서 며칠에 나눠 처리.
- **제외**: 개인과외교습자(개인정보 성격)는 이 데이터가 포함하더라도 싣지 않음. 폐원·휴원은 목록에서 빼고 상세는 "폐원" 표시.

```
apps/academy/            Next.js 정적 페이지(지역·지역×과목·상세 일부) + 작은 요약 데이터
apps/academy/worker/     Worker: /api/search(D1, 내 주변·조건 검색), /api/where, 상세 서버 렌더(D1)
```

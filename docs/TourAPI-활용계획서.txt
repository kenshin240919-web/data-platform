GuideJung TourAPI 활용계획서

1. 서비스명
GuideJung 여행·축제 정보 검색 서비스

2. 개발 목적
대한민국 관광지와 축제·행사 정보를 지역과 날짜 기준으로 검색하고,
사용자가 오늘 또는 이번 주말 방문할 장소를 결정하도록 돕는 웹서비스 개발.

3. 활용 데이터
한국관광공사 국문 관광정보: 지역·위치 기반 관광정보, 관광지 상세정보,
행사 일정, 법정동 코드, 분류체계 및 관련 안내 정보.

4. 주요 기능
지역별 관광지 검색, 오늘·주말 행사 검색, 개별 장소·행사 상세 조회,
주변 관광지 연결, 출처와 정보 확인일 표시.
무료·반려동물 등 조건은 공식 근거를 확인한 경우에만 표시.

5. 데이터 관리
API 이용한도를 준수하며 수집·정규화·지역 검증·중복 제거 후 제공.
미확인 정보는 확인 필요로 표시하고, 이미지 사용 시 개별 라이선스 준수.
인증키는 서버 환경변수로 관리하며 공개 저장소와 브라우저에 노출하지 않음.

6. 개발 및 공개 계획
현재 로컬 개발·검증 단계.
최종 검수 이후 trip.guidejung.com 여행 서비스와
home.guidejung.com 생활정보 허브를 별도 신규 환경에 배포할 계획.
기존 guidejung.com은 수정하지 않고 독립 운영.

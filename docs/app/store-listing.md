# 내근처 안드로이드 앱 — 구글 플레이 등록 자료 (2026-10-29)

앱은 **TWA(신뢰할 수 있는 웹 활동)**: 크롬으로 near.guidejung.com을 주소창 없이 열고, 다른 16개 내근처 사이트도 같은 앱 안에서 엽니다.
사이트를 고치면 앱에도 바로 반영됩니다(앱을 다시 올릴 필요 없음).

## 순서
1. GitHub Secret `TWA_KEY_PASSWORD` 추가(16자 이상, 직접 정한 긴 비밀번호 — 잊으면 업로드 키를 다시 만들어야 함)
2. Actions `내근처 앱 빌드` 실행 → 업로드 키·지문 자동 커밋, `.aab`·`.apk` 아티팩트
3. `make-assetlinks.mjs` 실행·배포(업로드 키 지문) → `.apk`를 휴대폰에 깔아 주소창이 안 보이는지 확인
4. Play Console: 앱 만들기 → 위 등록 정보·그래픽·설문 → 테스트 트랙에 `.aab` 업로드
5. Play Console → 테스트 및 출시 → 앱 무결성 → **앱 서명 키 인증서 SHA-256**을 `apps/app/play-signing.sha256`에 넣고 `make-assetlinks.mjs` 다시 실행·배포(플레이에서 받은 앱도 주소창 없이)
6. 개인 개발자 계정이면 비공개 테스트(테스터 12명 이상·14일 이상) 뒤 프로덕션 신청 — 조건은 Play Console 안내로 다시 확인
